# 网文套路结构化研究

> 目标：在 AI 生成内容之前，为用户提供可勾选的“套路选项”。本文件区分整本书级别的 **大套路** 与章节桥段级别的 **小套路**，并把每个套路拆成可用于后续产品结构化存储的字段。
>
> 覆盖来源：知乎写作讨论、B站写作教程、龙空网文讨论、起点/网文写作方法资料、网盘写作素材索引。网盘侧仅记录“资料流通线索”，不下载、不复述疑似侵权资料全文。

## 一、大套路 (Macro Tropes) 提取

- **套路名称 (Name)**: 废柴退婚逆袭流
- **核心卖点 (Core Hook)**: 读者爱看“被公开否定的人，用可见成长把羞辱原路打回去”；核心爽点是身份、实力、尊严三重翻盘。
- **阶段性里程碑 (Major Milestones)**:
  1. 开局：主角曾有天赋或身份，但跌落底层，被家族、宗门、婚约对象公开轻视。
  2. 触发：退婚、逐出、测试失败、被夺资源等事件把“必须证明自己”的主线钩子抛出来。
  3. 起势：获得戒指老爷爷、神秘传承、系统、血脉觉醒或重生记忆，开始低调补短板。
  4. 首胜：在小考核、小冲突、小副本中第一次反打，证明“废柴判断是错的”。
  5. 升阶：宗门大比、家族大会、学院选拔、秘境争夺等公共场合完成大规模打脸。
  6. 扩图：昔日退婚对象/压迫者只是第一层敌人，背后牵出更高阶势力和更大的命运主线。
- **必避毒点 (Macro Pitfalls)**: 羞辱不能堆到主角像受虐工具；退婚对象不能只会尖叫降智；金手指不能替主角完成所有判断；每次打脸都要推进资源、地位或主线，不能只循环“被嘲讽-暴打-震惊”。

- **套路名称 (Name)**: 系统面板成长流
- **核心卖点 (Core Hook)**: 把成长可视化、任务化、奖励化，让读者持续看到“下一点属性、下一个技能、下一次阶层跃迁”。
- **阶段性里程碑 (Major Milestones)**:
  1. 开局：主角处在普通人、底层职业、弱势家族或危机现场，现实目标明确但资源不足。
  2. 绑定：系统/面板/模拟器/熟练度/词条出现，给出第一个可完成任务和可见奖励。
  3. 试用：主角利用系统信息差完成第一次小胜，读者理解升级规则。
  4. 扩展：系统从单一奖励扩展到职业树、技能树、商城、模拟次数、词条组合或任务链。
  5. 代价：系统奖励需要风险、选择、限制或冷却，避免“点按钮就赢”。
  6. 破局：主角逐渐从“使用系统”变成“理解规则并反向设计局面”，系统成为工具而不是主人。
- **必避毒点 (Macro Pitfalls)**: 系统存在感不能强到主角失去主体性；任务不能像运营活动流水账；属性膨胀要有对手、世界规则和代价兜底；系统解释不要挤占情节现场。

- **套路名称 (Name)**: 无限流副本解谜升级流
- **核心卖点 (Core Hook)**: 用一个个高概念副本提供新鲜感，用生死规则和隐藏真相制造强期待，再用通关评价、奖励和队伍关系回收爽点。
- **阶段性里程碑 (Major Milestones)**:
  1. 开局：主角被卷入陌生空间、怪谈游戏、末日副本、主神任务或规则怪谈，必须立刻求生。
  2. 立规：第一个副本快速展示核心规则、死亡风险、评分体系和通关奖励。
  3. 首通：主角发现别人忽略的规则漏洞或人性线索，完成第一次高评价通关。
  4. 组队：固定队友、临时盟友、竞争者和组织势力出现，副本外主线开始成形。
  5. 变奏：副本类型轮换，例如校园怪谈、古宅献祭、末世列车、赛博公司、仙侠秘境。
  6. 揭幕：所有副本背后指向主神空间、世界污染、旧神复苏、现实阴谋或主角身世。
- **必避毒点 (Macro Pitfalls)**: 副本规则不能靠作者临时改；解谜不能只靠主角开天眼；队友不能全是挂件；副本之间要有长期主线和人物变化，否则会像短篇合集。

## 二、小套路 (Micro Tropes) 提取

- **桥段名称 (Name)**: 拍卖会捡漏打脸
- **核心目的 (Scene Purpose)**: 让主角低成本获取关键道具，同时公开证明主角眼力、金手指或专业知识高于反派和权威鉴定者。
- **必需角色站位 (Required Roles)**: 主角、嚣张反派、拍卖师/鉴定师、不识货旁观者、隐藏道具本体或旧主人线索。
- **情节节拍器 (Plot Beats)**:
  1. 压抑：一件冷门拍品被众人嫌弃，反派顺手嘲讽主角“穷酸/不懂行”。
  2. 识别：主角通过系统、记忆、传承、专业知识看出拍品另有玄机。
  3. 出手：主角低价竞拍，表现得像随手买小玩意，压住真实意图。
  4. 冲突：反派为了恶心主角抬价，旁观者笑主角上头。
  5. 释放：拍品解封、残图拼合、器灵苏醒、药材露真形，价值远超成交价。
  6. 余韵：旁观者震惊，反派懊悔破防，主角获得后续副本或升级钥匙。
- **微观毒点 (Micro Pitfalls)**: 反派不能只为抬价而抬价；捡漏逻辑要提前埋线；打脸要干脆，不要连续解释十页；宝物价值要服务后续剧情。

- **桥段名称 (Name)**: 宗门大比扮猪吃虎
- **核心目的 (Scene Purpose)**: 在公共竞技场完成实力认证，把前面积累的羞辱、训练、隐藏实力一次性回收。
- **必需角色站位 (Required Roles)**: 主角、轻视主角的同门/家族子弟、裁判或长老、观众、真正强敌。
- **情节节拍器 (Plot Beats)**:
  1. 压抑：赛前所有人依据旧标签判断主角必败，反派甚至安排羞辱性对阵。
  2. 藏锋：主角前几轮只用基础招式过关，让别人误判上限。
  3. 加压：反派或强敌逼主角暴露底牌，观众期待“废物原形毕露”。
  4. 反转：主角在关键回合使用新境界、新招式或隐藏理解，逆转局势。
  5. 释放：裁判、长老、旁观者意识到主角真实实力，旧评价崩塌。
  6. 余韵：主角得到名额、资源、师承或进入更大地图的资格。
- **微观毒点 (Micro Pitfalls)**: 不能为了隐藏实力让主角明明能赢却拖泥带水；裁判不能无脑偏袒到破坏规则可信度；大比结果必须改变主角处境。

- **桥段名称 (Name)**: 测试天赋震惊全场
- **核心目的 (Scene Purpose)**: 快速完成身份重估，建立主角潜力、稀缺性和势力争夺价值。
- **必需角色站位 (Required Roles)**: 主角、测试者/导师、围观群众、先前的天才标杆、质疑者。
- **情节节拍器 (Plot Beats)**:
  1. 预设：测试规则和普通/优秀/绝世档位先被清楚展示。
  2. 压低：主角因出身、年龄、旧失败记录被默认不可能合格。
  3. 对照：先让一个公认天才测出高分，建立读者期待上限。
  4. 爆表：主角测试结果异常，石碑裂开、灵根变色、机器宕机或数据溢出。
  5. 争夺：导师、宗门、公司或势力立刻改变态度，开始争抢主角。
  6. 挂钩：异常结果埋下身世、血脉、禁忌体系或更高等级世界观线索。
- **微观毒点 (Micro Pitfalls)**: “爆表”前必须让读者懂档位；震惊不能只堆感叹号；天赋高不等于立刻无敌；异常结果最好带来麻烦而不只是福利。

- **桥段名称 (Name)**: 英雄救美反被救
- **核心目的 (Scene Purpose)**: 反转传统救援桥段，建立女角色能力和主角的非脸谱魅力，同时制造轻喜剧或关系推进。
- **必需角色站位 (Required Roles)**: 主角、强能力女角色、误判局势的敌人、围观者或队友。
- **情节节拍器 (Plot Beats)**:
  1. 误判：主角以为女角色陷入危险，准备出手救人。
  2. 加压：敌人或环境让场面看似更危急，旁观者也默认女角色弱势。
  3. 出手：主角冲入局面，但发现自己判断不完整。
  4. 反救：女角色反手解决核心危机，顺便救下主角或补上他的漏洞。
  5. 释放：敌人被双重打脸，主角承认误判，女角色能力被读者接受。
  6. 余韵：两人形成互补关系，后续可发展搭档、暧昧或互相试探。
- **微观毒点 (Micro Pitfalls)**: 不能用“女强”反过来羞辱主角成小丑；女角色能力要提前有细节暗示；关系推进不要变成强行恋爱发糖。

- **桥段名称 (Name)**: 身份揭露压轴打脸
- **核心目的 (Scene Purpose)**: 用隐藏身份或隐藏资源回收长线铺垫，让敌人的傲慢在公开场合反噬。
- **必需角色站位 (Required Roles)**: 主角、势利反派、权威人物/组织代表、吃瓜群众、与主角身份相关的信物或记录。
- **情节节拍器 (Plot Beats)**:
  1. 压抑：主角因衣着、职业、家世、表面等级被拒绝、羞辱或抢功。
  2. 升级：反派把冲突推到公开场合，试图借权威定性主角。
  3. 暗线：主角此前留下的信物、人脉、战绩、订单或旧案开始回收。
  4. 揭露：权威人物到场，确认主角真实身份、贡献、级别或所有权。
  5. 释放：反派的判断链全部崩塌，旁观者从鄙夷转为敬畏。
  6. 余韵：身份揭露带来新麻烦，例如更高层敌人注意到主角。
- **微观毒点 (Micro Pitfalls)**: 隐藏身份不能只为装；主角不能长期纵容无意义羞辱；权威人物出场要有因果，不要像作者空投；揭露后要进入新局面。

## 三、扩展大套路库 (Macro Tropes)

- **套路名称 (Name)**: 神豪返利消费流
- **核心卖点 (Core Hook)**: 用“花钱越多越强”的反常识机制满足财富幻想，同时制造身份错位与消费打脸。
- **阶段性里程碑 (Major Milestones)**:
  1. 开局：主角穷、被看低、被分手或被现实压迫，获得返利/消费/投资系统。
  2. 发展：通过买车买房、投资公司、打赏主播、扶持女主/员工触发返利和人脉升级。
  3. 爆点：反派以为主角装富，结果资产、股权、银行流水或幕后身份曝光。
  4. 长线：从个人消费升级为商业帝国、慈善布局、产业控制或城市级影响力。
- **必避毒点 (Macro Pitfalls)**: 炫富不能只列价格；女角色不能全变拜金模板；返利规则要限制套娃刷钱；消费要能带来关系、信息或产业变化。

- **套路名称 (Name)**: 都市修仙重回地球流
- **核心卖点 (Core Hook)**: 仙尊级认知碾压现代社会，让读者看主角用超维能力重估亲情、财富、权力和仇怨。
- **阶段性里程碑 (Major Milestones)**:
  1. 开局：主角从仙界/末法时代归来，回到被欺辱、遗憾或亲人危机的时间点。
  2. 发展：用丹药、医术、武力、阵法解决都市小局，修复家庭与旧遗憾。
  3. 爆点：豪门、武道世家、地下势力或官方组织意识到主角不是普通人。
  4. 长线：地球灵气、上古秘境、域外势力、前世仇敌逐渐接入大地图。
- **必避毒点 (Macro Pitfalls)**: 仙尊不能为一点小事反复亲自下场；现代社会规则不能完全失效；降维打击要有情绪对象和长期目标。

- **套路名称 (Name)**: 赘婿翻身流
- **核心卖点 (Core Hook)**: 表面低位的主角被岳家和外人轻视，最终用隐藏能力、资源或格局完成家庭与社会地位反转。
- **阶段性里程碑 (Major Milestones)**:
  1. 开局：主角入赘、背锅、被亲戚羞辱，婚姻关系处于冷淡或互不信任。
  2. 发展：主角暗中解决公司、家族、医疗、商业或武力危机。
  3. 爆点：岳家公开危机中，主角身份、人脉或能力压轴曝光。
  4. 长线：从家庭小圈层升级到商战、权谋、江湖或国家级布局。
- **必避毒点 (Macro Pitfalls)**: 妻子不能长期无脑站反派；羞辱桥段不能无限复制；翻身后要换新矛盾，不要继续在饭桌打脸。

- **套路名称 (Name)**: 苟道长生流
- **核心卖点 (Core Hook)**: 反热血、反莽撞，以“活得久、算得深、低风险复利”提供安全感和长期见证感。
- **阶段性里程碑 (Major Milestones)**:
  1. 开局：主角拥有长生、寿元、稳健面板或避劫能力，但战力并非顶尖。
  2. 发展：通过低调修炼、避因果、积资源，看一代代天骄崛起陨落。
  3. 爆点：主角在别人以为他普通时，显露跨时代积累和极深底牌。
  4. 长线：宗门兴衰、王朝更替、灵气潮汐、天地大劫构成宏观时间感。
- **必避毒点 (Macro Pitfalls)**: 苟不能等于不行动；长期见证要有人物情感回收；主角过稳会稀释危机，需要周期性外部大劫。

- **套路名称 (Name)**: 迪化幕后流
- **核心卖点 (Core Hook)**: 主角普通操作被他人过度脑补成绝世布局，爽点来自信息差、误会升级和无心插柳。
- **阶段性里程碑 (Major Milestones)**:
  1. 开局：主角拥有身份、环境或话术误导，让旁人高估其层级。
  2. 发展：配角主动解释主角行为，把巧合脑补成深谋远虑。
  3. 爆点：脑补结果反过来帮主角完成布局，形成“假装高人变真高人”。
  4. 长线：追随者、敌人、组织不断扩张误会，主角被推上更大舞台。
- **必避毒点 (Macro Pitfalls)**: 误会必须有合理证据链；主角不能永远纯靠运气；配角不能集体降智；脑补要产生实际后果。

- **套路名称 (Name)**: 幕后黑手经营流
- **核心卖点 (Core Hook)**: 主角不直接冲锋，而是创造组织、马甲、传说或棋局，让世界按他的暗线运转。
- **阶段性里程碑 (Major Milestones)**:
  1. 开局：主角掌握情报、系统、分身、马甲或组织模板。
  2. 发展：建立第一个据点/教团/公司/情报网，制造可信传说。
  3. 爆点：各方势力被主角不同马甲牵动，却不知道源头是同一人。
  4. 长线：组织扩张、马甲冲突、世界危机与主角真实目的交织。
- **必避毒点 (Macro Pitfalls)**: 马甲太多会混乱；幕后操盘也需要代价；不能让全世界只配合主角演戏。

- **套路名称 (Name)**: 第四天灾召唤玩家流
- **核心卖点 (Core Hook)**: 用“玩家不怕死、会整活、能爆肝”的群体行为改变异世界，兼具经营、战争和沙雕爽点。
- **阶段性里程碑 (Major Milestones)**:
  1. 开局：主角成为领主、神明、NPC或系统宿主，获得召唤玩家能力。
  2. 发展：玩家建村、刷怪、搬砖、探索，把弱小势力滚雪球做大。
  3. 爆点：本土势力第一次见识玩家复活、协作和不按套路出牌。
  4. 长线：玩家版本更新、阵营战争、世界真相和主角权限升级。
- **必避毒点 (Macro Pitfalls)**: 玩家群像不能喧宾夺主；游戏机制要自洽；沙雕不能破坏主线严肃危机。

- **套路名称 (Name)**: 规则怪谈求生流
- **核心卖点 (Core Hook)**: 让读者和主角一起解读规则，在禁忌、反转和极限试错中获得智斗爽感。
- **阶段性里程碑 (Major Milestones)**:
  1. 开局：主角进入学校、医院、公寓、列车、公司等封闭规则场。
  2. 发展：规则出现真假、遗漏、冲突，主角通过细节识别生路。
  3. 爆点：主角利用规则反杀怪异、救队友或拿到隐藏评价。
  4. 长线：多个怪谈场景拼出污染源、旧神、系统或现实阴谋。
- **必避毒点 (Macro Pitfalls)**: 规则不能事后补丁；解法不能靠作者强行解释；恐怖氛围和逻辑谜题要平衡。

- **套路名称 (Name)**: 末世囤货安全屋流
- **核心卖点 (Core Hook)**: 把现实焦虑转化为“提前知道灾难并准备充足”的掌控感。
- **阶段性里程碑 (Major Milestones)**:
  1. 开局：主角重生/预知末世，知道极寒、丧尸、洪灾、酸雨或秩序崩塌即将到来。
  2. 发展：囤货、改造安全屋、建立团队、筛选可信关系。

  4. 长线：资源争夺、基地政治、异能进化、灾难真相推进。
- **必避毒点 (Macro Pitfalls)**: 囤货清单不能写成购物流水；主角不能毫无人性；安全屋太无敌会失去冲突。

- **必避毒点 (Macro Pitfalls)**: 不能只靠前世信息碾压；复仇对象要有层级；主角不能为了虐而牺牲无辜。

- **必避毒点 (Macro Pitfalls)**: 原主不能纯粹背锅；剧情知识不能万能；远离主线和参与主线的动机要稳定。

## 四、扩展小套路库 (Micro Tropes)

- **桥段名称 (Name)**: 宴会羞辱反杀
- **核心目的 (Scene Purpose)**: 在高社交压力场景中完成身份或能力反转。
- **必需角色站位 (Required Roles)**: 主角、宴会主人、势利宾客、挑衅反派、权威贵客。
- **情节节拍器 (Plot Beats)**: 1. 入场被看轻；2. 反派公开羞辱；3. 主角暂忍观察；4. 贵客/证据/能力到场；5. 反派失态；6. 主角获得新社交入口。
- **微观毒点 (Micro Pitfalls)**: 不要让所有宾客都像同一个嘴脸；打脸后要有资源变化。

- **桥段名称 (Name)**: 同学会阶层反转
- **核心目的 (Scene Purpose)**: 用旧关系重逢制造现实阶层和个人成长对照。

- **微观毒点 (Micro Pitfalls)**: 不要把同学会写成全员势利；反转要有铺垫信号。
